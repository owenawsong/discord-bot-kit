# Changelog

## 0.2.1

- Rename the repository, package, primary CLI, agent skill and workspace to discord-bot-kit.
- Preserve legacy command alias, state environment/path, evidence replay, session header and complete ticket markers.
- Rework README and launch material around local development, executable scenarios and agent integration.

## 0.2.0

- Versioned custom JSON namespaces with guild/global scopes, atomic transactions, scalar updates, validation and defensive copies.
- Advanced scenarios: named captures, typed references, replay, exact/absent JSON-pointer assertions, parallel batches and transport fault fixtures.
- Token-free session/scenario evidence, validated checkpoint restoration and isolated replay.
- Slash subcommands/groups, shared read-only autocomplete and typed Discord embeds with constraint validation.
- Poll reference bot implemented entirely on the generic namespace API.
- Custom scenario-file and state-introspection MCP tools, contract-aware local doctor, three recipe scaffolds.
- Namespace aliasing and malformed pointer issues caught by independent review and covered by regression tests.

## 0.1.0

- Shared command/component handlers for local simulation and discord.js.
- Shared slash argument schemas, six types, required values, choices, numeric/string bounds, local forms and registration translation.
- Interactive workshop with buttons, modals, select menus, actor switching, diagnostics, state inspection and evidence export.
- Complete ticket recipe with authorization, concurrent submission reservations and recoverable remote effects.
- Complete event signup recipe with durable rosters, capacity limits, idempotent join/leave, closure permissions, pagination and ordered updates.
- CLI scaffold, JSON scenario runner, command preview and offline configuration checks.
- Local stdio MCP tools and focused agent instructions.
- Atomic single-writer JSON persistence, redacted live diagnostics and loopback API protection.

Live Discord integration is implemented but has not been exercised against an authenticated test guild in this release preparation. The local checks do not establish production Discord fidelity.
