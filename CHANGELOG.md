# Changelog

## 0.1.0

- Shared command/component handlers for local simulation and discord.js.
- Shared slash argument schemas, six types, required values, choices, numeric/string bounds, local forms and registration translation.
- Interactive workshop with buttons, modals, select menus, actor switching, diagnostics, state inspection and evidence export.
- Complete ticket recipe with authorization, concurrent submission reservations and recoverable remote effects.
- Complete event signup recipe with durable rosters, capacity limits, idempotent join/leave, closure permissions, pagination and ordered updates.
- CLI scaffold, JSON scenario runner, command preview and offline configuration checks.
- Local stdio MCP tools and focused agent instructions.
- Atomic single-writer JSON persistence, redacted live diagnostics and loopback API protection.

Live Discord integration is implemented but has not been exercised against an authenticated test guild in this release preparation. The local checks do not establish production Discord fidelity.
